数据文件夹

画布都存在这一个文件夹里：spaces/ 是一个画布一个文件夹。 换文件夹时会先问旧的要拷贝一份留着、剪贴走，还是干脆新建一份不带过去。

图片生成

Images 协议直接出文生图；带参考图时走 edits。Chat 协议把提示词和图发进对话。 走 API 时步数、CFG、种子、负向这些本地参数不生效，高清放大自动走本地放大模型。 并行数 = 同时最多跑几张（1–10）；本地模型固定一次一张。

模型文件都放在下面这个文件夹里，扔进去就能用。点「检测模型」看这台机器装得下哪一档、还缺哪几个文件。

视频生成

把 MiniMax-H3 的四个权重文件放进下面这个文件夹，应用会自动识别扩散模型、视频 VAE、音频 VAE、文本编码器；文件名不一样也能认，认不出的会提示改名，缺的会给下载链接。出片 1–20 秒、带声音；每条要几分钟，和本地生图抢显存。

文生视频、图生视频走远端 API。海螺和 OpenAI 协议直接吃画布上的首帧图；万相和百炼可灵只收公网图片 URL，本地首帧暂不支持。任务提交后服务端停不掉，按秒计费。并行数 = 同时最多跑几条（1–10）；本地模型固定一次一条。

3D 模型库

把 .glb 文件放进下面这个文件夹，3D 面板里就能调用到。 3D 面板不支持用户手动创建，需要时可以让 agent 通过 MCP 调用。

3D 生成

右键图片块「生成 3D 模型」：本机从单张图生成几何模型（Hunyuan3D 标准版），结果进 3D 模型库。需要 CUDA 12 显卡，生成时约两分半，期间可以取消。 「生成带纹理的 3D 模型」会连颜色纹理一起做，总共约五分钟。

权重许可：腾讯混元 3D 2.0 社区许可（欧盟、英国、韩国不可用；商业使用需遵守许可条款，月活超过一百万需申请授权）。

云端 3D 生成服务的接入配置（协议、接口地址、Key、模型名）。当前版本云端协议还没接上，生成请用本地模型。

宇宙贴图

内置的星体贴图是 2K，飞近了看表面会有点糊。这里是同一套贴图的 8K 版，共 7 张， 点一次下载到数据文件夹的 cosmos/ 里，之后离线照用；不升级也完全不影响飞行。

    Agent 连接（MCP）

    别的 agent 可以通过本机 MCP 操作画布。复制连接配置贴到它那边即可； 服务只监听 127.0.0.1，token 只存在本机配置里。

    快捷键

    当前画布的键盘操作一览。这里只做说明，暂不支持自定义。

    画布

    全选面板 CtrlA
    复制选中的面板（有文字选区时复制文字） CtrlC
    粘贴面板、图片、音频或文字 CtrlV
    原地复制并粘贴选中的面板 CtrlD
    锁定 / 解锁选中的面板（都锁着就一起解开） CtrlL
    锁定 / 解锁某一块 Ctrl左键双击
    删除选中的面板 Delete/Backspace
    微移选中的面板（按住 Shift 走 10 倍） ↑↓←→
    按住 Alt：量选中面板到四周最近面板的距离（拖动时实时更新） Alt
    鸟瞰窗选中后移动视野（Shift 走得更远） ↑↓←→
    缩放回到 100% Ctrl0
    缩放画布（以指针为中心） Ctrl滚轮
    平移画布 滚轮
    依次放下画面笔、退出摆放 / 鸟瞰窗焦点、画图工具、选中 Esc

    3D 场景

    摆放模式下移动家具（右键进入） 左键拖动
    退出家具摆放 Esc
    旋转视角 Ctrl左键拖动
    整体平移视图 Shift左键拖动
    推近 / 拉远 滚轮

    搜索

    打开搜索（再按一次聚焦并全选） CtrlF
    输入 #1 直接定位并选中 1 号面板（实时） #数字
    切换搜索结果 ↑↓
    跳到选中的结果 Enter
    关闭搜索 Esc

    编辑

    结束文字、笔记或文件编辑 Esc
    在笔记或文件编辑器里缩进两个空格 Tab
    撤销（笔记、文件编辑器、画面块笔画） CtrlZ
    重做 CtrlShiftZ/CtrlY
    保存连线标签（Esc 取消） Enter
    生图提示词：开始出图（Shift+Enter 换行） Enter
    就地输入时确认 / 取消（缩放比例、间隔分钟） Enter/Esc

    弹窗与浮层

    确定当前弹窗 Enter
    关闭弹窗、菜单、主题面板或取色板 Esc
    在多选弹窗里切换选项 ↑↓

    窗口

    收起 / 恢复软件标题栏 F10

    视频组件

    画布里的视频碰到本机放不出声的音轨（AC3、DTS 这类）时，要靠 ffmpeg 把那条音轨转成 AAC。没装它画面照样能播，只是那条视频不会响。 要修就把 ffmpeg.exe 放进下面这个文件夹，再点重新检测。
