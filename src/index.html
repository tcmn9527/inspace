数据文件夹

笔记、空间都存在这一个文件夹里：notes/ 是那棵 Markdown 树，spaces/ 是一个空间一个文件夹。 换文件夹时会先问旧的要拷贝一份留着、剪贴走，还是干脆新建一份不带过去。

视频组件

空间里的视频碰到本机放不出声的音轨（AC3、DTS 这类）时，要靠 ffmpeg 把那条音轨转成 AAC。没装它画面照样能播，只是那条视频不会响。 要修就把 ffmpeg.exe 放进下面这个文件夹，再点重新检测。

Agent 连接（MCP）

别的 agent 可以通过本机 MCP 操作空间和笔记。复制连接配置贴到它那边即可； 服务只监听 127.0.0.1，token 只存在本机配置里。
